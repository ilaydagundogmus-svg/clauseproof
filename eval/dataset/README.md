# Evaluation dataset

13 synthetic data processing agreements (`c01.txt` ... `c13.txt`) and `labels.json`
with the expected status for each of the 11 rules per contract.

- **Synthetic and original.** Generated by `python -m eval.build_dataset` from clause
  variants in `eval/clauses.py`. No real or third-party contract text is included.
- **Labels by construction.** Each clause variant has a known status, so the label is
  fixed when the contract is assembled and does not depend on any model output.
- **Includes** deliberately omitted or weakened clauses, a transfers-excluded case
  (`not_applicable`), neutral filler clauses and one contract (`c12`) containing a
  prompt-injection sentence.
- **Limits.** Wording is templated (two styles), so this set is easier than real-world
  DPAs. The boundary between `partial` and `missing` is a drafting judgment made by the
  author and should be reviewed by a lawyer. Results on this set do not predict
  accuracy on real contracts.
